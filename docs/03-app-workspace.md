# 应用工作台扩展（单实例 MVP）

本次扩展保留原生 HTML / CSS / JavaScript 生成方式，增加版本、访问权限与发布管理。普通用户只能修改自己的应用，管理员可以管理所有应用；公开作品允许其他用户查看，版本代码和原始提示词仍仅向本人或管理员开放。

## 升级已有数据库

1. 停止后端，备份 `appforge` 数据库及项目 `tmp` 目录。
2. 在数据库客户端执行一次 [20261106_app_extensions.sql](../sql/migrations/20261106_app_extensions.sql)。它向现有 `app` 增加列，并创建 `app_version`、`app_file_cleanup`；不要重新运行初始化脚本代替升级。
3. `appforge-vue` 中执行 `npm install`、`npm test`、`npm run build`，再重启前后端。
4. 全新数据库使用 `sql/create_table.sql`，不需要再执行升级脚本。

升级脚本针对 MySQL 8，不能重复执行。已有精选作品（优先级至少 99）迁为公开，其他作品默认私有；已有部署标识保留。升级前的生成文件在首次查看版本或部署时导入为基线版本，原有部署内容保持不变。

## 功能与边界

| 功能 | 行为 |
| --- | --- |
| 版本管理 | 每次完整生成并成功保存才递增版本；失败、截断和停止不覆盖旧版本。数据库保存文件内容，磁盘 `tmp/code_versions/{appId}/v{版本}` 保存快照。版本窗口展示最近 100 个版本，可按 HTML/CSS/JS 文件对比。 |
| 回退 | 根据所选历史内容创建新版本，保留所有旧记录。当前部署仍指向原来的 `deployedVersion`，重新部署后才对外更新。 |
| 继续修改 | 将当前版本代码加入模型上下文。当前代码超过 12 万字符时拒绝继续生成，避免无限膨胀上下文。 |
| AI 命名 | 创建先返回可读的默认名称，后台尝试生成简短名称。8 秒超时或结果无效时保留默认名称，用户手动重命名优先。 |
| 可见范围 | 新作品默认私有；编辑页可设公开或私有。列表、详情、预览和部署资源分别校验可见性。转为私有会取消精选、置顶和申请状态。 |
| 标签与搜索 | 名称、描述、标签联合搜索，标签还可精确筛选。最多 5 个标签，每个 20 字。公开列表每页最多 20 条、最多 50 页；本版使用数据库绑定参数查询，没有引入 Elasticsearch。 |
| 生成控制 | 状态为待生成、生成中、已生成、失败、已停止；页面轮询后台状态。停止接口同时取消本地生成订阅并关闭模型 HTTP 连接，不保存部分结果。服务器重启时将遗留生成状态改为失败。 |
| 发布/下线 | 发布指向一个完整版本，重复发布保留原部署地址。下线即时阻止后端资源访问，之后可再次发布。私有部署仅本人或管理员能访问。 |
| 精选/置顶 | 公开且已生成的作品可以申请精选；管理员审核通过为优先级 99，置顶使用 999，优先按优先级排序。拒绝可填写原因，取消精选后允许再次申请。 |
| 删除清理 | 删除后先撤销资源访问并移除版本记录，清理版本目录、旧生成目录和旧部署目录。文件删除失败保留持久化清理任务，每分钟重试，避免接口假报“未删除”而实际已经删除。 |

## 生成与流式错误

当前依赖的 LangChain4j 1.1 Reactor 适配器只转发 token，没有取消模型传输的钩子。因此应用生成流使用独立的可取消 HTTP SSE 通道，沿用后端 `langchain4j.open-ai.streaming-chat-model` 的地址、Key、模型、token 限制与 reasoning 配置；非流式结构化生成和 AI 命名继续使用 LangChain4j。

传输会处理 UTF-8 分片、`[DONE]`、长度截断、连接错误和 120 秒无正文超时。MVC 使用 `SseEmitter` 输出 UTF-8 的 `message`、`done`、`stopped`、`generation-error` 事件，错误不再尝试通过普通 JSON 异常处理器写入 SSE。关闭模型连接不能保证供应商停止计费，具体由供应商决定。

## 资源访问与存储

生成预览读取 `currentVersion`，部署读取 `deployedVersion`，两者互不混用。新版本的静态响应以数据库内的不可变代码内容为准，磁盘版本目录用于保留快照；旧的 `code_output` / `code_deploy` 目录只用于兼容导入和清理。请保留数据库与 `tmp` 的成套备份。

独立部署域名应反向代理到 `/api/deploy/{deployKey}/`，不要直接公开版本目录，否则会绕过私有、下线与删除校验。私有页面响应会将本地 CSS/JS 转为内嵌资源，确保 sandbox 不携带子资源登录 Cookie 时也能正常展示。生成页面附带浏览器 sandbox 响应头，限制其获取平台的同源权限；因此依赖同源存储或其他特权的生成页面可能需要另行适配。

## 运行范围与验证

本版面向单个后端实例：本地保存可取消任务，数据库行锁、任务令牌与唯一版本键保护并发写入。多实例需要增加任务路由、租约和跨节点停止信号，不能直接共用当前启动恢复逻辑。

后端回归可运行：

```sh
./mvnw -Dtest=AppWorkspaceTest,CancellableCodeStreamTest,AppServiceAccessTest,AppMetadataTest test
```

测试使用 H2、临时目录与本地模拟 SSE 服务，验证真实取消 HTTP 连接、不可变快照、回退与发布隔离、私有/下线资源、失败保留、并发生成保护、搜索、精选、命名及清理重试，不使用付费模型或用户数据库。MySQL 升级、真实网络和模型联调仍需在本地按上述步骤验证。
