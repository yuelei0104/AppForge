# 按提供文档接入可视化修改

本次依据用户提供的《可视化修改》文档，沿用当前工作区、版本快照、原生生成与 Vue 构建流程，按文档顺序接入以下内容。

| 文档步骤 | 当前实现 |
| --- | --- |
| 选中网页元素与动态注入 | `utils/visualEditor.ts` 管理编辑状态、悬浮虚线、选中实线、选择器、文本和页面路径；通过 postMessage 与当前预览 iframe 通信 |
| Vite 同源代理 | 开发环境 `/api` 代理到 `http://localhost:8123`，`.env.development` 使用相对 API 地址；生产环境需由同域反向代理转发 `/api` |
| 修改对话页面 | 选中元素显示在输入框上方，可关闭；输入框显示当前编辑对象。编辑入口按文档提示词置于发送按钮左侧，同时保留文档后续代码中的预览栏入口，两者共用状态 |
| 发送元素信息 | 发送前按文档顺序追加页面路径、标签、选择器、当前内容；展示及提交同一份消息。提交后清除选中状态并退出编辑；沿用现有 2000 字请求上限 |
| 原生应用全量修改 | 现有提示词已包含文档的修改约束；进一步明确恰好一个完整 HTML 块，或 HTML/CSS/JavaScript 各一个完整代码块，保留已有三文件完整性要求 |
| Vue 工程增量修改 | 复用现有提示词与 ProjectTask 的先读目录、再读文件、局部替换流程；目录、读、写、改、删拆为五个工具类，补充重要入口文件删除保护 |
| 工具输出优化 | BaseTool 定义格式化接口，ToolManager 管理工具数组。写入显示文件内容，修改显示替换前后内容，读取/目录/删除显示对应路径；继续区分失败与成功，历史不保存重复的“选择工具”提示 |

## 与现有项目的必要适配

当前预览响应携带 `sandbox allow-scripts allow-forms`，即使经过同源代理，父页面也不能直接读取 iframe 的 contentDocument。因此使用预览响应中的小型桥接脚本接收父窗口发来的文档编辑脚本。桥接仅在本人请求 `?visualEditor=1` 预览时注入；公开访问者和部署入口不注入。生成源码、版本快照、下载文件和部署文件中不加入编辑器。保留原 sandbox 响应头，不授予生成网站父页面同源权限。

消息只接受当前 iframe 的 contentWindow，并检查类型、字段和大小；子页面只接受父窗口的编辑命令。停用、切换应用、预览重载和离开页面时清理高亮、选中状态、监听器和待执行定时器。

文档示例使用应用目录和 ToolMemoryId；当前生产流程使用每次生成独立的 ProjectTask。五个工具保留当前 SDK 工具名及参数 `readDirectory/path/before/after`，通过 ToolManager 为每次任务创建独立绑定数组，复用当前路径限制、源码预算、取消和构建流程。Spring 管理的工具模板不保存某个应用的可变状态，避免并发生成串用工作目录。`readDirectory` 已递归返回允许的源码列表，node_modules、dist、隐藏文件等不属于可操作源码。

Vue 的平台固定依赖、版本预算和构建步骤保持既有约定。已有旧版 VueProjectTools 继续兼容现有调用，生产 Runner 使用新管理器返回的五个绑定工具。没有增加新模型、命令执行工具或额外云服务。

## 运行

拉取后重启 Vite，使 `/api` 代理配置生效；后端仍按现有方式启动。后端改为其他端口时，同步调整 Vite 代理目标。若本机 `.env.local` 已设置绝对 API 地址，它会覆盖开发环境配置，需要改为 `/api`，或配置实际可访问的后端地址。

生产部署前端时，需要将同域 `/api/` 反向代理到后端 `/api/`，并保留 Cookie 与 SSE 流式响应。相对 API 地址不包含密钥。

应用成功生成后，本人在对话页点击“编辑模式”，悬浮或点击预览元素，在输入框描述修改并发送。原生模式返回完整页面；Vue 模式通过读改文件工具修改现有项目并重新构建。新版本仍由现有工作区流程保存，已部署版本不会因预览修改自动切换。

## 验证边界

自动化验证使用本地测试模型与测试数据库，不使用用户 API 密钥、不调用付费模型。真实模型能否完全遵循局部修改要求仍需本机联调，不能据模拟测试声称任意页面修改准确率得到保证。

基线已有 `AppCreationModeTest` 的四个空指针错误：手工创建的测试对象未注入新增路由服务。本次不改动无关路由业务或该测试夹具，测试结果中单独区分这一已知问题。

本次本地验证：154 项相关后端测试、38 项前端测试全部通过；前端类型检查、生产构建及本次修改文件的 ESLint 检查通过。真实浏览器验证了原生页面与实际构建后的 Vue 页面选中、发送上下文、版本更新、退出编辑、访客只读及 390px 手机布局。浏览器测试使用本地模型响应，不代表已验证付费模型的修改准确率。
